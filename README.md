# Agents

A comprehensive repository dedicated to exploring and building **diverse varieties of intelligent agents** from scratch. This project focuses on innovative, explorative agent development with implementations ranging from simple reactive agents to complex autonomous systems.

## 🎯 Project Overview

This repository serves as a sandbox for experimenting with different agent architectures, behaviors, and paradigms. Whether you're interested in reinforcement learning agents, LLM-powered agents, rule-based systems, or multi-agent systems, you'll find implementations and examples here.

## 🏗️ Repository Structure

```
Agents/
├── README.md
├── explorative/          # Experimental agent implementations
├── reactive/             # Simple reactive agents
├── learning/             # Reinforcement learning based agents
├── llm-agents/           # Large language model powered agents
├── multi-agent/          # Multi-agent systems
├── utils/                # Shared utilities and helpers
└── examples/             # Usage examples and demonstrations
```

## 🤖 Agent Types

### Explorative Agents
Agents designed to explore and discover optimal strategies through trial and error, suitable for novel problem domains.

### Reactive Agents
Simple, stimulus-response agents that make decisions based on current state without internal memory or planning.

### Learning Agents
Agents that improve their performance over time using reinforcement learning and other ML techniques.

### LLM-Powered Agents
Agents leveraging large language models for reasoning, decision-making, and natural language interaction.

### Multi-Agent Systems
Coordinated systems of multiple agents working together to solve complex problems or simulate emergent behaviors.

## 🛠️ Development

### Creating a New Agent

1. Create a new directory under the appropriate category
2. Implement the agent class inheriting from base classes in `utils/`
3. Add documentation and examples
4. Include unit tests
5. Update this README with description

### Running Tests

```bash
pytest tests/
```
